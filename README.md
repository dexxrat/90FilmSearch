## About

My first IT project. A single-page web application that finds movies by user-entered quotes or phrases. The frontend was hand-coded from a custom Figma design as an introduction to web development.

---

## Tech Stack

- HTML
- CSS (custom design, responsive)
- Vanilla JavaScript
- Figma (design)

---

## Features

- Search movies by quote or phrase
- Random movie display on page load
- Responsive design (desktop, tablet, mobile)
- Custom animations and transitions
- Keyboard shortcuts (Ctrl+K to focus search)
